# decree

An event-sourcing toolkit for Elixir: a Postgres event store (`Decree.Store`) and a CQRS framework (`Decree`) on top of it.

Derived from [Commanded](https://github.com/commanded/commanded) and [EventStore](https://github.com/commanded/eventstore) by copying the code sparkle.space uses, with no fork and no upstream history. MIT; the upstream notices are in `NOTICE`.

Status: bootstrap (sparkle.space P2, sparkle-space/sparklespace#7498). Private.
